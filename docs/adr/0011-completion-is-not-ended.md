# 「判定完成」≠「播完」：媒体还在播就不离开本节点，安全网先复查一个窗口期

`0010` 的「推进」有个隐含前提：**「本节点已经没有可播的未完成任务点了」就等于「本节点的事已经结束」**。2026-09-30 在真机上把这条前提推翻了——**平台的「判定完成」可以大幅早于媒体播完**。实测：一条 489 秒的视频在 `currentTime=437`（89%，**还剩 53 秒**）时容器就戴上了 `ans-job-finished`（上报 URL 里的 `rt=0.9` 就是那个完成比例），而**章节树上的 `input.jobUnfinishCount` 还要再等 3–6 秒**才被平台自己那次 `studentstudycourselist` 刷新掉。

于是脚本的第 8b 步（「本节点已无可播单元 → 当场离开」）必然踩进那几秒：DOM 说「本节点一个未完成任务点都没有了」、树还说「有」→ `0010` 的安全网判「解释不清」→ `stop(treeUnfinishedNotFound)`。用户报障的那条原文就是它（`本卡片 1/1 | 后面还有 18 个… | 1324/1482s | 还剩 158s`），而且**只要视频的完成比例 < 100% 就必现**：同一门课里另外三条视频（`rt=1`）都在 `ended` 那一刻才 FIN，脚本走「播完固定等一段」那条路，一次都没停 —— 这组对照把根因钉死了。

因此改成两条：

- **媒体还在播就不离开本节点**：8b 的提前出口只对「没在播」（暂停 / 已结束 / 加载失败）生效；正在播就让它播到 `ended`，走既有的「播完固定等一段」。这同时把少看的那几十秒补回来（承 `0002` 的「如实完播」），并把竞态容差从 0 秒拉到几十秒。
- **安全网不再一票否决，先复查一个窗口期**（新常量 `TREE_RECHECK_GRACE_MS = 15000`）：树说本节点还有未完成、脚本却一个未完成任务点都没看到时，先等满这个窗口，到期仍不一致才 `stop(treeUnfinishedNotFound)`。

## Considered Options

- **只用窗口期、不改第 8b 步**：放弃。窗口能挡住这一次（滞后 3–6 秒 < 15 秒），但脚本仍然会在 89% 处丢下没看完的视频走人 —— 那正是 `0002` 反对的「不是如实完播」。
- **只改第 8b 步、不加窗口期**：放弃。它够用只是因为「判定的那一刻媒体还在播」；判定若落在暂停 / 加载失败那一刻（8b 仍放行），或者树的刷新慢过播完那 15 秒，同一类误停立刻回来。两条互不依赖，便宜的保险不该省。
- **窗口期复用 `ADVANCE_DELAY_MS`**：放弃。使用手册明确建议「嫌翻节慢就把它调小到 5 秒」，而窗口必须大于平台刷新树的往返（实测 3–6 秒）—— 共用一个常量等于让一次正常的调参把这个修复悄悄调坏。
- **记一笔「刚刚有任务点从不完成变成完成」就不停**：放弃。它更精准，但会**削弱安全网**：`0010` 要防的「适配层漏判一个真任务点」那类事故里，脚本也刚看到过一次完成 —— 同样被放过。复查窗口不改判据强度，只给它一点时间。
- **把 `sawUnfinished` 改成在播放期间也累积**：放弃。同上，等于让安全网永不触发（正常流程里脚本必然看到过未完成任务点）。

## Consequences

- **新增**：常量 `TREE_RECHECK_GRACE_MS`；等待 `PENDING.TREE_UNFINISHED_MISMATCH`（放弃类：`再等 N 秒复查章节树（仍不一致就停下）`）；记忆 `treeMismatch = { nodeId, since }` —— 带 nodeId 是为了「换节点重新计时」，旧账不会把新节点的窗口提前用光；跳节点时一并清掉。`treeUnfinishedNotFound` 的文案加一句「又等了 15 秒复查仍是如此」，时限照纪律由常量拼。
- **行为变化两处**：① 本节点没有可播单元、但媒体还在播时，脚本从「立刻换卡片 / 跳节点」变成「等它播完」—— 多花的就是那条媒体剩下的时间（实测一次 53 秒）；② 判定不可信从「立刻停」变成「先等 15 秒」。
- **`0010` 的意图不变**：推进仍然是「从章节树只向前跳到下一个未完成节点」，那张安全网仍然在，只是从「一票否决」改成「复查后再否决」。
- ⚠️ **`docs/sites/xuexitong.md` 里两条旧措辞被就地更正**：`jobUnfinishCount`「随完成实时变化」→「服务端往返级，滞后 3–6 秒」；`videoFaceCaptureEnc` 是「课程启用人脸抓拍」的标志 → 与真实抓拍对不上（连带一条未复现的观察也记在那里）。
