# 学习通 · 自动播放下一节

在学习通的**学习页面**上，把当前节点的视频/音频任务点挨个播完，播完自动推进到下一个任务点。装好之后它自己开跑，**不需要你点任何按钮**。

---

## 这是什么

- 打开学习页面 → 右下角出现一个小黑窗 → 脚本开始工作；
- 依次播完本节点的视频/音频：直接播放，**不需要**你先点开任务点、也不需要静音；
- 本卡片播完了就切下一张卡片；本节点确实没有能播的了，就**从章节树直接跳到后面的第一个未完成节点**（只向前，中间那些早已完成的节点一个都不访问）；
- **不伪造观看**：不改播放进度、不碰平台的上报数据、除确认框外不替你点任何东西。

它做不到的事，见下面「这个脚本不做什么」。

---

## 开始使用

**准备**：一台电脑，浏览器用 **Chrome** 或 **Edge**（脚本按这两个的行为写），以及能登录学习通的账号。全程大约 **3 分钟，不需要懂代码**。

### 第一步：装篡改猴（Tampermonkey）

「篡改猴」是一个浏览器扩展，脚本靠它才能运行。

1. 打开扩展商店：

   - Chrome：<https://chromewebstore.google.com/search/tampermonkey>
   - Edge：<https://microsoftedge.microsoft.com/addons/search/tampermonkey>

2. 在搜索结果里找到 **Tampermonkey**（图标是两个圆圈叠成的猴子头，作者是 **Jan Biniok**），点进去 → 点 **「添加至 Chrome」** 或 **「获取」** → 弹窗里点 **「添加扩展」**。

   > ⚠️ 商店里有很多名字相似的扩展，认准 **Tampermonkey** 这个名字和那个猴子头图标。装错了脚本不工作。

3. 装好后，浏览器右上角会多出一个**小猴子图标**。

   - 没看到图标是正常的：新版浏览器会把扩展折叠起来。点一下地址栏右边的**拼图图标**（🧩），在列表里找到 Tampermonkey，点旁边的图钉把它钉出来更好找。

4. 点一下那个猴子图标，能看到它的菜单（「添加新脚本」「管理面板」……），就说明装好了。

### 第二步：装脚本

需要脚本文件 [`src/xuexitong-auto-next.user.js`](./src/xuexitong-auto-next.user.js)。

> 如果这个文件已经有人发给你了，直接用你手上那份，跳过这一句。

**方法 A：拖进去（最简单，推荐）**

1. 找到那个 `.user.js` 文件（一般在「下载」文件夹里），把这个文件**直接拖到浏览器窗口中间**，松手；
2. 页面会自动跳到 Tampermonkey 的**安装页**，上面有一个大大的 **「安装」** 按钮 —— 点它；
3. 看到「已安装成功」之类的提示就好。

> 如果拖进去只看到满屏代码、没弹安装页，说明篡改猴没装好，回到第一步。

**方法 B：复制粘贴**

1. 点猴子图标 → **「管理面板」**（或「添加新脚本」）→ 点 **「+」**，会出现一个满是代码的编辑框；
2. 把里面的内容**全部选中删掉**（`Ctrl+A` 再 `Delete`）；
3. 打开脚本文件，把内容**全部复制**过来粘贴进去；
4. 按 `Ctrl+S` 保存。

### 第三步：确认跑起来了

打开任意一个学习通的**学习页面**（播放视频的那个页面，不是课程列表页），页面**右下角**会出现一个小黑窗，写着「学习通 · 自动播放下一节」——看到它就说明一切正常，脚本**自己会开始干活**。

没有小黑窗？看下面「出问题怎么办」。

---

## 用它之前必须知道的三件事

1. **想自己暂停，请点小黑窗上的「停止」**，不要用播放器上的暂停键。脚本会把播放器上的暂停当成意外，几秒后自动帮你继续播。
2. **同一时间只开一个学习通的章节页面、只登一台设备。** 同一个账号在第二处进入章节页，平台会判定异常学习并把你先前的会话踢下线（**同一个浏览器里另开一个章节标签页也算**）。
3. **脚本不会自己更新。** 拿到新版本的 `.user.js` 后，**把第二步再做一遍**，安装页上点「重新安装」（或「更新」）覆盖掉旧版。

---

## 这个脚本不做什么

- **启用了人脸抓拍的课，脚本用不了**，只能手动看。检测到就立刻停下。
- **PPT 类任务点脚本处理不了**：承载 PPT 的查看器在另一个域，父页面读不到也驱动不了它。脚本的做法是**跳过它，并替你点平台的确认框**。
- **不会让「本节点未完成 N」归零**：那个数由平台给出、含 PPT，只要节点里有 PPT 就一直大于 0 —— **不代表脚本卡住了**。
- **不伪造观看**：从不改播放进度、不碰上报数据；停下就是停下，不会静默跳节。

各个任务点的实际行为、状态条怎么读，见[使用手册](./docs/usage/xuexitong-auto-next.md)。

---

## 出问题怎么办

**右下角没有小黑窗？**

1. 确认你打开的是**学习页面**（播放视频的那个页面），不是课程列表页；
2. 点猴子图标，看「学习通 · 自动播放下一节」是不是**已启用**；
3. **刷新一下页面**（按 `F5`）；
4. 还不出来，就是脚本没装上 —— 回到第二步重做一遍。

**拖文件进去没反应 / 只看到代码？**

篡改猴没装好或没启用，回到第一步；也可以改用「方法 B」手动粘贴。

**脚本跑着跑着停下来了？**

小黑窗开头写的就是**为什么停**。照着[使用手册第五节「停下之后怎么办」](./docs/usage/xuexitong-auto-next.md)那张表处理即可。状态条读法的完整说明也在那「使用手册」里。

**想卸载？想换电脑？**

卸载：点猴子图标 →「管理面板」→ 在「学习通 · 自动播放下一节」那一行右边点**删除**（🗑）。连篡改猴一起卸掉，就在浏览器的扩展管理页里删掉 Tampermonkey。
换电脑 / 换浏览器：**要重装**，插件和脚本都重装一遍（脚本装在浏览器里，不会跟着账号走）。
